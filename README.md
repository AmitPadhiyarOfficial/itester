# itester — Four-Operation Calculator

A small C# console calculator supporting addition, subtraction, multiplication, and division.

## Requirements

- .NET 8 SDK

## Run

```sh
dotnet run
```

Enter expressions with spaces, for example `12 + 3.5`, `8 / 2`, or type `q` to exit. Decimal numbers use a period.
